Edebî Biyografi ve Düşünce Çizgisi

Âgâh Hukukî, kalemini hakikatin ve vicdanın emrine vermiş bağımsız bir yazar ve şairdir. Yayıncılık hayatı boyunca edebiyatın estetik gücü ile düşüncenin yalın adaletini bir araya getirmeyi hedeflemiştir.

"Hukuk-u Beşer" ismi, klasik Osmanlı düşünce geleneğindeki evrensel insan hakları kavramına bir saygı duruşu niteliğinde olup; herhangi bir siyasi kalıba veya dar kalıplara sığınmaksızın, insanı merkeze alan edebî bir duruşu temsil eder.

Deneme, eleştiri ve şiirleri çeşitli edebiyat dergilerinde yayımlanan yazar, dijital arşiv sitesi üzerinden okurlarıyla bağımsız diyalog kurmayı sürdürmektedir.

PHP + MySQL Sunucu Entegrasyonu

Sitenizi PHP ve MySQL sunucusuna taşımak için hazır veritabanı şeması ve bağlantı kodları.

1. MySQL Veritabanı Tablosu (SQL)

Hosting ortamınızdaki phpMyAdmin veya MySQL veritabanına aşağıdaki SQL komutunu çalıştırabilirsiniz:

CREATE DATABASE IF NOT EXISTS `hukuku_beser` DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
USE `hukuku_beser`;

CREATE TABLE IF NOT EXISTS `articles` (
  `id` INT AUTO_INCREMENT PRIMARY KEY,
  `title` VARCHAR(255) NOT NULL,
  `slug` VARCHAR(255) NOT NULL,
  `category` VARCHAR(100) NOT NULL,
  `excerpt` TEXT,
  `content` LONGTEXT NOT NULL,
  `image` VARCHAR(500),
  `is_featured` TINYINT(1) DEFAULT 0,
  `created_at` DATETIME DEFAULT CURRENT_TIMESTAMP
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

CREATE TABLE IF NOT EXISTS `poems` (
  `id` INT AUTO_INCREMENT PRIMARY KEY,
  `title` VARCHAR(255) NOT NULL,
  `author` VARCHAR(150) NOT NULL,
  `category` VARCHAR(100) NOT NULL,
  `content` TEXT NOT NULL,
  `created_at` DATETIME DEFAULT CURRENT_TIMESTAMP
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

2. PHP Veritabanı Bağlantı Dosyası (config.php)

<?php
// config.php - Sunucu Veritabanı Bağlantısı
$host = "localhost";
$db_user = "db_kullanici";
$db_pass = "sifreniz";
$db_name = "hukuku_beser";

try {
    $db = new PDO("mysql:host=$host;dbname=$db_name;charset=utf8mb4", $db_user, $db_pass);
    $db->setAttribute(PDO::ATTR_ERRMODE, PDO::ERRMODE_EXCEPTION);
} catch(PDOException $e) {
    die("Veritabanı Bağlantı Hatası: " . $e->getMessage());
}
?>
